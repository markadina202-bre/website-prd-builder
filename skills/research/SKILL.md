# research — Riset sumber primer via agen latar (distilasi)

- repo: mattpocock/skills (`skills/engineering/research`)
- url: https://github.com/mattpocock/skills
- install: `npx skills@latest add mattpocock/skills` (isi penuh di repo sumber)
- role: Delegasikan riset ke agen latar yang membaca sumber primer.

## Trigger
Butuh fakta docs/API/standar, atau legwork bacaan yang bisa jalan paralel.

## Prinsip inti
- Agen latar jalan sementara kita lanjut kerja lain.
- **Sumber primer saja** (docs resmi, source code, spec, API first-party) — bukan tulisan sekunder tentangnya. Tiap klaim dilacak ke pemiliknya.
- Output: 1 file Markdown temuan, tiap klaim dikutip sumbernya, disimpan mengikuti konvensi repo.

## Pakai di proyek ini
Pengayaan grill (validasi klaim user soal kompetitor/teknologi) + tiket Research Wayfinder.

## Batasan
Riset tanpa pertanyaan tajam = rangkuman generik. Pertanyaan dulu, riset kemudian.
