# writing-shape — Bahan mentah menjadi artikel (distilasi)

- repo: mattpocock/skills (`skills/in-progress/writing-shape`)
- url: https://github.com/mattpocock/skills
- install: `npx skills@latest add mattpocock/skills` (isi penuh di repo sumber)
- role: Exploit — tumpukan bahan SUDAH final, komitmen ke struktur, gali per paragraf.

## Trigger
Ada tumpukan bahan (jawaban grill, form, tiket, catatan) yang harus jadi dokumen satu suara.

## Prinsip inti
- Loop: baca tumpukan PENUH → tetapkan prerequisite (grounding awal) → draf 2–3 opening beda sudut (user pilih/hybrid) → tumbuh paragraf per paragraf ("apa yang perlu didengar pembaca berikutnya?") → tulis langsung ke file tiap blok disepakati.
- **Grounding**: tiap KONSEP harus grounded (prasyarat ATAU diperkenalkan blok sebelumnya) sebelum blok boleh bersandar padanya. Satuannya konsep, bukan kata.
- Gerakan: "paragraf ini berbuat apa yang sebelumnya tidak?" / "kalau saya potong, apa yang rusak?" / "ini prosa atau seharusnya list?" / "opening janji X, kita melenceng ke Y."
- Tumpukan = tambang (pecah/gabung/parafrase, satu suara), bukan naskah. Gap DIBERI NAMA ("butuh contoh, tumpukan tak punya — beri sekarang atau potong seksi ini").
- Pilihan format disengaja: prosa vs list vs tabel (3+ baris struktur sama) vs callout vs kutipan vs code block.
- Baca ulang file sebelum tiap tulis (user bisa edit di antaranya); jangan overwrite buta.

## Pakai di proyek ini
Kualitas prosa FASE 5 (PRD Final): tumpukan artefak → dokumen yang mengalir.

## Batasan
Jangan tambah bahan baru di luar tumpukan; jangan edit file bahan; jangan urus publishing.
